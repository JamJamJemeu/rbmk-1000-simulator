# Changelog / Historia zmian / История изменений

## 1.0.3 — 2026-11-15

**PL**
- Uszkodzenie paliwa nie kończy już gry od razu: paliwo pęka, kanały się deformują i blokują pręty (czerwona linia na skali), a para z rozerwanego paliwa dalej podbija moc – aż do wybuchu, jeśli nie opanujesz sytuacji. Uszkodzone kanały widać na kartogramie.
- „Noc testu” startuje o 01:20, bliżej stanu z 1986: test + AZ-5 kończy się jak wtedy. Uratować reaktor można tylko powolnym wsuwaniem prętów RR.

**EN**
- Fuel damage no longer ends the game at once: fuel cracks, channels deform and block the rods, and steam from failed fuel keeps raising power until the core ruptures. “Night of the test” now starts at 01:20, closer to the 1986 state.

**RU**
- Повреждение ТВЭЛ больше не завершает игру сразу: каналы деформируются и блокируют стержни, пар поднимает мощность до разрушения. «Ночь испытания» начинается в 01:20.

## 1.0.2 — 2026-11-15

**PL**
- Naprawiono błąd „setValueAtTime… -0.005”, który przy pierwszym kliknięciu w Chrome blokował grę ekranem błędu.
- Ekran błędu pokazuje się już tylko wtedy, gdy gra w ogóle nie wystartuje.

**EN**
- Fixed the “setValueAtTime … -0.005” audio error that blocked the game on the first click in Chrome. The error screen now appears only if the game fails to start.

**RU**
- Исправлена ошибка звука «setValueAtTime … -0.005», блокировавшая игру при первом нажатии в Chrome.

## 1.0.1 — 2026-11-15

**PL**
- Gdy plik otworzy się w podglądzie bez JavaScriptu (Messenger, WhatsApp, Gmail, podgląd plików), zamiast pustej strony pojawia się instrukcja, jak go otworzyć w przeglądarce. Przy błędzie uruchomienia wyświetla się jego treść.
- Lepsza zgodność ze starszymi przeglądarkami.

**EN**
- When the file is opened in a preview without JavaScript, a message explains how to open it in a browser instead of a blank page; startup errors are shown on screen. Better compatibility with older browsers.

**RU**
- При открытии в просмотрщике без JavaScript вместо пустой страницы показывается подсказка; ошибки запуска выводятся на экран. Улучшена совместимость со старыми браузерами.

## 1.0.0 — 2026-11-15

**PL**
- Pierwsze wydanie: pulpit RBMK-1000 w stylu radzieckiej sterowni (kartogram rdzenia, przyrządy, pręty RR / AR / USP / AZ, pompy 1–8, AZ-5 pod osłoną, sygnalizacja, dziennik komputera „SKAŁA”).
- Fizyka: kinetyka punktowa, ksenon i jama jodowa, dodatni współczynnik parowy, efekt końcowy prętów, zabezpieczenia AZM / AZS.
- Tryb zmiany z planem dyspozytora, awariami i naganami.
- Odtworzenie nocy 26.04.1986 z narracją, grywalny scenariusz „Noc testu”, ukryty easter egg.
- Sekwencja wybuchu: trzęsienie konsoli, pękające szkło, zgaśnięcie światła.
- Język polski (domyślny) i rosyjski.

**EN**
- First release: Soviet-style RBMK-1000 control panel, simplified reactor physics, shift mode, replay of the night of 26 April 1986, playable “Night of the test” scenario, hidden easter egg, Polish and Russian interface.

**RU**
- Первый выпуск: пульт РБМК-1000 в советском стиле, упрощённая физика реактора, режим смены, запись ночи 26.04.1986, сценарий «Ночь испытания», пасхалка, польский и русский интерфейс.
